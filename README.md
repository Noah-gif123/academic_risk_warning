# 学情预警系统（v2.0）

面向高校课程的过程性学情预警系统。教师录入考勤与成绩、学生在线作答、导员与教务分级处置，系统按“**数据来源 → 风险判定 → 处置闭环**”三条链给出可解释、可复算的预警结论。

- 核心判定：缺课超 1/3 的硬门槛（确定性）、加权分与扣分的班内相对风险、置信度分级；**跨班可比（教师尺度 Δ + 课程因子 c）属第三阶段，代码里保留字段但未启用**
- 四端门户：学生 / 教师 / 辅导员 / 教务，共用一套账号与令牌
- 每条结论都带**触发依据快照**（缺课次数、允许上限、期末需考分、覆盖率），可事后逐项对账

## 快速开始

1）数据库（MySQL 8.0）

```bash
mysql -uroot -p -e "create database study_warning_system_v2 default charset utf8mb4;"
# 建表：v2.0/sql 下按序执行 01→15
# 演示数据（一条主线 + 一段历史 + 一个合成样本学期）：
#   19_cleanup_demo.sql → 20_rebuild_demo.sql → 21_tidy_after_rebuild.sql
```

2）后端（JDK 17）

```bash
cd v2.0/backend
./gradlew bootRun            # 或 ./gradlew build -x test 后 java -jar build/libs/*.jar
# 默认端口 8080；数据源见 src/main/resources/application.yml（可用 DB_USERNAME / DB_PASSWORD 覆盖）
```

3）前端（Node 18+）

```bash
cd v2.0/frontend
npm install
npm run dev                  # http://localhost:5173，/api 已代理到 127.0.0.1:8080
```
