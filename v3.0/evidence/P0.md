**本轮踩到的本机坑**（已写入 HANDOFF 第六节）

1. 本机因工作区目录未继承 DSH 沙箱所需的权限/完整性标签，命令行一度完全不能写文件；已修复（`.dsh-acl-recovery/` 留有记录）。新克隆/新机器可能重现。
2. 本机 PowerShell 执行策略限制：`.ps1` 必须用 `-ExecutionPolicy Bypass` 运行；v2.0 的 `rebuild_demo.ps1` 内部调用未加 Bypass，直接跑会失败。
3. 用 `Start-Process` 启动的 Java 进程会随命令结束被沙箱清理；验收时应通过后台作业启动。
