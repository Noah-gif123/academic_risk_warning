## P0-7 C1/C2 消融：修前 vs 修后

**口径**：C1 效应量 = 关闭某个 C 通道因子后，**风险等级发生变化的学生比例**（与 v2.0 `AblationTool` 同口径；工具先做 100% 复算自检，复算等级必须与库内一致）；C2 = 阈值单变量扫描（±3 / ±5 分）。

**修前 vs 修后总表（term 5）**

| 因子 | 修前 v2.0（540 行） | 修后 v3.0（1,927 行） | PLAN 目标 | 结论 |
|---|---|---|---|---|
| 教师松紧 | 1.48% | **2.39%** | 1.5–3% | ✅ 达标 |
| 课程类型因子 | 3.33% | **8.51%** | 2–4% | ❌ 超上限 |
| 历史挂科率因子 | 0.00%（`course_factor` 全 NULL，因子未生效） | **7.78%**（36/36 已初始化，3 历史学期生效） | 1–2% | ❌ 超上限（修复后首次生效） |
| 个人前科因子 | 0.19% | 7.42% | —（非 P0 目标） | 记录 |
| 全部关闭 | 3.89% | 21.38% | — | 记录 |

**分布（修后）**：基线 RED 141 / ORANGE 138 / YELLOW 383 / GREEN 1265 → 关闭课程类型 111/97/391/1328；关闭历史挂科率 114/100/390/1323；关闭教师 133/137/383/1274；全部关闭 96/24/313/1494。

**C2 阈值扫描（修后）**：红阈值 70/75/80 → RED 170/141/117；橙阈值 55/60/65 → ORANGE 232/138/85；黄阈值 35/40/45 → YELLOW 482/383/281。阈值小幅移动即显著改变分布，说明当前数据在阈值附近密度较高。

**原因分析（为什么两项超目标）**

1. **规模差异**：修后 1,927 行 vs 修前 540 行；等级变化率是比例指标，但对"阈值附近人数密度"更敏感；
2. **风险分布更宽**：v3 红黄占比 34.4%（修前 22.0%），更多学生处于阈值附近；
3. **历史因子从"完全未生效"变为"9 门课 × 3 历史学期全生效"**，因子标准差远大于修前（修前只有 course 7 单点 1.20，其余 1.00）；
4. **课程类型因子为 ±10%（1.10/0.90，PLAN 决策口径）**，在更大且更靠近阈值的人群上作用，等级变化率自然高于 540 行样本。

**结论**：C1/C2 对照已产出、口径可复算（自检 100%），教师松紧达标；课程类型 / 历史挂科率两项超出 PLAN 目标，**如实标注为「部分达标」**。不通过修改数据或配置硬凑目标——那会破坏 PLAN 已确认的 C 通道因子口径与 P0-4 挂科率区间。
