1.3 挂科率口径（已定）
议题
结论
★ 成绩构成归属
课程组（同一科目下所有老师共用同一套构成）。开学由课程组统一确定（例：平时 40% + 期末 60%），学期内锁定、不再变动
★ 老师差异的影响
老师差异只体现在主观分打分风格上，不影响挂科率计算，也不影响阈值可比性
★ 总课次定义
课程表中「教学周数 × 每周课次」，不采用老系统任何字段
退课
退课期内正式退选的，根本不在选课名单里；有充分理由教务批准可删除
缓考
等最终成绩齐全了再算
缓考后弃考
直接挂科（不管平时分多高，没成绩不可能够 60）
旷考 / 退考
挂科，属学生自身原因
分母口径
教务在考前二次确认「实际考核人数」
一致性校验
成绩录入后跑核对：实际录入人数 vs 实际考核人数，不一致提示教务，不能让分母悬空
重修生
学校一般单独开一个授课班，班里只有重修生
统计粒度
三方统计：教学班（→老师）/ 行政班（→导员）/ 课程总（→入历史）
课程级汇总
按人数加权平均，不能简单取平均
历史值初始化
先手动往数据库写一个值，后续学期由教务算完自动更新

「我们计算挂科率应该是按教学班、行政班、该科目三方数据，教学班挂科率反馈给老师，行政班挂科率反馈给导员，该科目总挂科率记录历史更新下一学期的科目历史挂科率。」
「现在是统一的了，因为一个科目下所有老师的成绩构成是一样的，只是不同老师会在主观分上有所出入，不影响计算（我认为）。假定开学课程组老师统一确定成绩构成平时分 40%，期末 60% 就不会再变动。」

2. 算法层（旧算法整体作废，重新设计）
2.1 三通道架构（产品形态）
通道 A：确定性风险 —— 规则引擎，0 算法，100% 可信
    已缺课 > 总课次/3          → 必然挂科
    剩余可缺次数 <= 1          → 高危
    扣分后期末需要分 > 历史期末最高分 → 实际不可达
    ▸ 第 2 周起可用（有点名数据即可），一根 SQL 就能上
 
通道 B：班内相对风险 —— 不需要 Δ，第 2~3 周起
    出勤扣分（学校统一规则，绝对量）
    作业提交行为（客观）
    主观得分班内排序（同班同尺度，不需要折算）
    ▸ 输出：本班风险排序，供导员 / 班主任
    ▸ 第 1~8 周的主力
 
通道 C：跨班 / 跨课程可比风险 —— 需要 Δ 和 c，第 6~9 周起
    期中成绩（A 层锚点，已确认是统一命题统一阅卷的强锚）
    + 教师尺度 Δ + 课程因子 c
    ▸ 输出：全校可比风险分 + 跨班对比，供教务
核心价值：三条通道可以分期落地、互不阻塞；输出不合并成一个风险分 —— 导员看 A+B，教务看 C。
2.2 ★ 出勤不是数据项，是「确定性规则」（本轮扣分规则已完整）

原话（本轮重申）：「迟到算迟到一节课扣一分，缺课一节课扣两分，请假前三次不扣分，后三次每次请假扣一分一节课」
扣分直接在总分上扣，不涉及平时成绩（100 → 98）。由此主公式确定为「加权 + 减法」：
加权分 W   = 平时分 × r_p + 期中 × r_m + 期末 × r_f
违纪扣分 P = 2 × N缺课 + 1 × N迟到 + 1 × max(0, N请假 − 3)
最终总评 T = W − P
 
硬门槛（独立于分数）：N缺课 > 总课次 / 3   →   直接挂科
总课次     = 课程表.教学周数 × 课程表.每周课次
             （★ 本轮定：不用老系统的 total_class_times）
 
★ 成绩构成统一：r_p / r_m / r_f 由课程组开学时确定后锁定，
   同一科目所有老师共用 → 跨老师比较无构成差异噪声

2.3 教师尺度 Δ 的估计方法
方法经历了三次升级，最终定在 v3：
版本
方法
被什么推翻
v1
班级均分差
❌ 混合了「老师严」和「学生差」，分不开
v2
期末双差分（平时班间差 − 期末班间差）
❌ 期末太晚，且很多课没有 / 不干净
v3（现行）
学生跨课程对比（双向固定效应）
已定

s(i,k) = μ + α_i + β_k + γ_t(k) + ε
    α_i = 学生效应（要剥离）
    β_k = 课程效应（要剥离，需按专业组分别估计）
    γ_t = 教师效应（= 我们要的 Δ）
估法：交替去均值，迭代 5~10 轮，约束 Σα = Σβ = Σγ = 0
识别逻辑：张老师班学生在别的课上正常、只有这门低 8 分 → 老师严；在所有课上都低 8 分 → 学生差。
核心优势：不需要任何统一考试，第 6~8 周即可用。期末双差分没有废弃，降为它的一个特例。
★ 本轮利好：A7 已明确「同一科目下所有老师成绩构成完全一致且学期内锁定」—— 跨老师比较不再混入占比差异噪声，Δ 的可识别性显著提高，这是原始算法没预料到的干净条件。
配套的三个必做处理：
专业组 × 课程交互项 β_(k,major) —— 四史这类跨学科公选课的必要条件
置信度收缩 λ = n/(n+k)，Δ̂ = Δ × λ，k ≈ 60 —— 新老师自动少生效，不需要写任何「是不是新老师」的分支
分项级而不是整体级（对应「不同老师对不同作业给分不同」）
防双重计算的铁律：
Δ → 只用「班 vs 课程平均」，不许出现课程历史数据
c → 只用「课程级」挂科率，绝对不许按老师 / 教学班拆算
否则张老师的「严」被算两遍，他班学生被过度保护
