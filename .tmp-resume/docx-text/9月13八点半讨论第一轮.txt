2. 算法层（旧算法整体作废，重新设计）
2.1 三通道架构（产品形态）
通道 A：确定性风险 —— 规则引擎，0 算法，100% 可信
    已缺课 > 总课次/3          → 必然挂科
    剩余可缺次数 <= 1          → 高危
    扣分后期末需要分 > 历史期末最高分 → 实际不可达
    ▸ 第 2 周起可用（有点名数据即可），一根 SQL 就能上
 
通道 B：班内相对风险 —— 不需要 Δ，第 2~3 周起
    出勤扣分（学校统一规则，绝对量）
    作业提交行为（客观）
    主观得分班内排序（同班同尺度，不需要折算）
    ▸ 输出：本班风险排序，供导员 / 班主任
    ▸ 第 1~8 周的主力
 
通道 C：跨班 / 跨课程可比风险 —— 需要 Δ 和 c，第 6~9 周起
    期中成绩（A 层锚点，若有）+ 教师尺度 Δ + 课程因子 c
    ▸ 输出：全校可比风险分 + 跨班对比，供教务
核心价值：三条通道可以分期落地、互不阻塞；输出不合并成一个风险分 —— 导员看 A+B，教务看 C。
2.2 出勤不是数据项，是「确定性规则」
已确认的学校规则：
缺席一次点名            → 总分扣 2 分
缺课超过 总课次 1/3      → 直接挂科（无特殊情况）
请假前 3 次不扣分，之后每次扣 1 分
扣分直接在总分上扣，不涉及平时成绩（100 → 98）
推出的四个结论：
出勤是全系统唯一「学校统一规则 + 完全客观 + 有明确分值」的数据源 → 根本不需要折算
主公式从「纯加权」改成「加权 + 减法」：
加权分 W   = 平时分 × r_p + 期中 × r_m + 期末 × r_f
违纪扣分 P = 2 × 未请假缺课次数 + 1 × max(0, 请假次数 − 3)
最终总评 T = W − P
硬门槛（独立于分数）：已缺课 > 总课次 / 3  →  直接挂科
UI 文案结论：每缺 1 次课（未请假）→ 期末需要多考 2 ÷ 期末占比 分

出勤数据的单向性：absent_count 是「已被发现的」缺课次数，是真值的下限 —— 老师点名越少只会低估，绝不虚高。所以可以放心当高危信号用，不会误报，只会漏报。

已定

s(i,k) = μ + α_i + β_k + γ_t(k) + ε
    α_i = 学生效应（要剥离）
    β_k = 课程效应（要剥离，需按专业组分别估计）
    γ_t = 教师效应（= 我们要的 Δ）
估法：交替去均值，迭代 5~10 轮，约束 Σα = Σβ = Σγ = 0
识别逻辑：张老师班学生在别的课上正常、只有这门低 8 分 → 老师严；在所有课上都低 8 分 → 学生差。
核心优势：不需要任何统一考试，第 6~8 周即可用。期末双差分没有废弃，降为它的一个特例。
配套的三个必做处理：
专业组 × 课程交互项 β_(k,major) —— 四史这类跨学科公选课的必要条件
置信度收缩 λ = n/(n+k)，Δ̂ = Δ × λ，k ≈ 60 —— 新老师自动少生效，不需要写任何「是不是新老师」的分支
分项级而不是整体级（对应「不同老师对不同作业给分不同」）
防双重计算的铁律：
Δ → 只用「班 vs 课程平均」，不许出现课程历史数据
c → 只用「课程级」挂科率，绝对不许按老师 / 教学班拆算
否则张老师的「严」被算两遍，他班学生被过度保护
边界与退化（已列全）：单教学班 → Δ=0；样本<30 → λ<0.33；新老师 → Δ̂=0；无统考项 → Q=0 退化为纯均值偏移；折算后 clip 到 0~100；|Δ|>20 标记异常推教务复核；评分项构成变化 → 新项 Δ=0。

2.7 影子分数（已定，无争议）
折算分只活在风险引擎里，绝不回写 score_info。老师看原分、学生看原分、教务看「原分 + 折算分对照视图」、引擎用折算分。
2.8 高考分 D 层
摸底考与高考分不是二选一：摸底考 = 提前到第 1 周的 A 层；高考分 = D 层先验。不互斥，是叠加
★ 高考分自动退役：
第 0~4 周  高考分 100%
第 5~6 周  60% + 跨课程锚 40%
第 7 周后  30% + 跨课程锚 70%
期中之后   ≤ 10%（基本退场）
→「软件工程该看哪个高考科目」这个难题自动消失，因为它 4 周后就退场了
基础课（英语 / 高数 / 大物 / 化学）→ 科目级映射可用
专业课 → 不做科目映射，改「位次百分位 + 首选科目分组」：物理组 / 历史组各自组内标准化，绝不跨组比较；用位次百分位而非原始分；不刻画选科组合
