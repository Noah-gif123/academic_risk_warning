## 二、冻结时点确认的关键口径

**角色与账号**：四端（学生 / 教师 / 导员 / 教务）共用一个登录页，账号分别为学号、教职工号、教务专用账号（如 admin100），默认密码 `000000`。

**数据来源（本版核心）**：新增课程内容与教学活动层——导学、教学目标、目录（课前 / 课中 / 课后）、测验、作业、项目；教师发布、学生提交、教师批改，形成一手过程数据。

**成绩构成**：开课前由教师确定评分项与权重、课程组确认后锁定；评分项分**自动型**（随堂测试、单元检测、作业、项目，批改后自动入分）与**手工型**（实验报告、课堂表现等，教师录入或导入）；**考勤与资料都不作为评分项**。

**活动规则**：题型为单选 / 多选 / 判断 / 填空 / 简答；客观题系统判分、主观题教师批阅，**每题记录判卷人**；**缺考 / 未交记 0 分**；**作业与项目都不允许迟交、不允许补交**；教师不代交；答案与解析由教师发布时设为“永远不可见”或“批阅后可见”。

**项目与贡献度**：项目提交文件（Word / PDF / Java 代码 / PPT 等）；团队项目由**组长提交一份贡献表**，提交后不可修改、教师也不可修改；个人得分 = 项目总分 × 个人贡献占比。

**考勤**：双轨制（平时用于预警 / 归档用于判定）；只做教师端点名；每节课可发布但不强制；**考勤次数不低于课次的 1/3**（提醒、督办、置信度判低均按此线）。

**邀请码**：教师生成 → 学生申请 → 教师同意 → 系统给教务一条**知会**记录（教务不审批）。

**学情预警**：以“安全边际”为核心，按三族规则取最高等级；课程侧三因子校正（课程难度、课程历史挂科率、教师评分尺度 Δ）；**Δ 只在教务端展示**；学生端按可见性规则裁剪（剩余可缺次数为 0 时才提示“再缺一次即挂”，不显示剩余数值）；**不做趋势图**。

**其他**：通知只做站内信；问卷当前只有“教师风格判定”一种，按行政班发放、匿名；学期写法统一为“2026-2027学年-第1学期”；教师可**置顶 / 结课**，结课后学生端不再显示；退课与休学不计入班级比例，重修班单独统计。

**明确不做**：知识点相关全部删除；课程编码彻底删除；课程封面上传、课程简介与公告、课程详情“基础设置”页签、教学任务类提醒、题库与按知识点推荐练习、期末考试进系统（考试课为纸质 / 上机）、邮件与短信、每日快照与趋势图、AI 阅卷（第三阶段）。
