# 课程资料原件投放目录

把 4 门课的资料原件丢进本目录（或按课程建子目录），我来做「解析 → 分块 → 入库 → 同步到 Dify 知识库」。

## 需要哪几门课

| 课程 | 现在语料 | 目标 |
| --- | --- | --- |
| 大学计算机基础（一） | 已有导学 + 第1/2讲 + 实验二 + 三级项目 + 复习提纲（约 20 块） | 补齐后续讲次 |
| 高等数学（一） | 只有导学（4 块） | 课件/习题/章节要点 |
| 数据结构（Java） | 只有导学（6 块） | 课件/习题/大作业说明 |
| 计算机网络 | 只有导学（6 块） | 课件/习题/实验指导 |

「四史概述」只有导学也够用，可以不补。

## 支持格式

`.pdf` `.docx` `.pptx` `.txt` `.md`（`.doc` / `.ppt` 老格式请另存为新格式）

## 命名建议

```
kb-source/
  大学计算机基础/
    第3讲_公式与函数进阶.pptx
    第4讲_数据管理.pdf
    习题集_第1-6讲.docx
  高等数学/
    第1章_函数与极限.pdf
    ...
```

文件名会成为报告与问答里的「依据：文档名 第N段」，所以**名字要写清楚**（讲次/章节/用途），别用 `新建文档1.docx`。

## 说明

- 本目录内容**不入 git**（体积与版权原因），只提交解析后的 `ai_kb_chunk` 数据与生成脚本。
- 目标是单门课 50 块以上、全库 200+ 块；分块粒度约 300–400 字，带 20% 重叠。
- 我不会替你编造课程内容；没有原件的部分，语料就保持现状，并在评测里如实反映。
